# AI Agents Learning Path

A complete, beginner-friendly learning path for training fresh graduates to use **open-source AI agents** for web scraping, deep research, content creation, testing, and autonomous coding tasks.

**All tools are free or <$20/month. No CS degree required.**

## 🚀 Start Here

👉 **[learning-path/index.md](learning-path/index.md)** — Main entry page with full table of contents

## What You'll Learn

- Set up AI coding agents (OpenCode, Oh My Pi, Claude Code)
- Connect tools to agents using MCP (Model Context Protocol)
- Build custom agents for specific tasks
- Run powerful LLMs locally (Ollama, llama.cpp)
- Automate real-world tasks: research, reporting, deployment, system management
- Build portfolio-worthy projects
