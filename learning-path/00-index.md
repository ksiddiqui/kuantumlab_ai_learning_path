# Learning Agent-Driven Automation: A 40-Hour Path Built Entirely on Free Tiers

> **Your journey from zero to building AI agents that can research, code, scrape, and deploy — using only free and open-source tools.**

## What You'll Learn

This learning path teaches you how to use **AI agents** — tools that can take actions on your computer, search the web, read your emails, write code, and produce reports. By the end of this path, you'll be able to:

- Set up powerful AI coding agents (OpenCode, Oh My Pi, Claude Code) on your computer
- Connect any tool to any agent using **MCP (Model Context Protocol)**
- Build custom agents for your specific tasks
- Run powerful LLMs locally on your machine (Ollama, llama.cpp)
- Automate real-world tasks: research, reporting, deployment, system management
- Build portfolio-worthy projects and showcase them

## Prerequisites

- Basic Python knowledge (variables, functions, HTTP requests)
- A computer running Windows, macOS, or Linux
- 40 hours to complete the full path

No computer science degree required.
