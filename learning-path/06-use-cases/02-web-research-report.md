# Use-Case 2: Deep Internet Research + Comparative Report (PDF + Excel)

> **Produce a professional LLM provider comparison report — complete with pricing tables, feature grids, and executive summary — in both PDF and Excel format, fully generated by an AI agent.**

## Understanding Deep Internet Research

> This use case combines three agent capabilities: **web search** (find sources), **deep extraction** (read full pages), and **multi-format output** (PDF + Excel). The agent orchestrates these tools itself — you only need to provide the research question and quality constraints.

### What Is It?

- A **web search MCP** (Exa, SerpAPI, or Firecrawl Search) lets the agent find fresh, authoritative sources on a topic.
- A **Firecrawl MCP** or web-fetch tool lets the agent read the full text of search results, not just snippets.
- The agent then synthesizes findings into a structured report and exports it to **PDF** (via a report-generation skill or `pandoc`/LaTeX) and **Excel** (via a spreadsheet MCP or `pandas`/`openpyxl`).

### Why You Need This

- **Professional reports** are the #1 deliverable in consulting, product management, and data analyst roles. Learning to generate them programmatically is a marketable skill.
- This workflow exercises **multi-tool orchestration** — the agent must decide which tool to call, in what order, and how to synthesize their outputs. That is the core skill of building capable agents.
- The **Excel export** teaches you how to produce data consumers can filter and pivot — far beyond a static PDF.

## Before You Start

**Setup required:**
- Web search MCP installed (Exa or Firecrawl) — see [Section 3](01-local-machine.md)
- Firecrawl MCP or a web-fetch MCP installed
- OpenCode or OMP with model access (DeepSeek for cheap research, Claude for synthesis)
- Python with `pandas`, `openpyxl`, and `reportlab` installed locally

**Cost estimate:** $0–$2 (DeepSeek API is free; Exa/Firecrawl have free tiers; the only cost is your LLM token usage).

## Step-by-Step Guide

### Step 1: Research LLM Pricing Models and Features

**Prompt:**
```text
I am writing a comparative research report on LLM providers for software development tasks (coding, reasoning, code review). Use your web search tool to find the latest information from 2024–2026 on the following providers: OpenAI (GPT-4o, o1, o3), Anthropic (Claude 3.5/4 Sonnet, Opus), Google (Gemini 2.0/2.5 Flash and Pro), and DeepSeek (V3).

For each provider, extract:
- Pricing per 1M input tokens and 1M output tokens
- Context window size
- Multimodal support (yes/no, what types)
- Agent tool-calling capabilities (yes/no)
- Code editing benchmarks (HumanEval pass@1 score if available)
- Any stated roadmap items for 2026

Search at least 10 authoritative sources (official docs, blog posts, benchmark leaderboards). Cite each source with a URL. Summarize in a structured format I can use in a spreadsheet.
```

**What the agent does:**
1. Uses the web search MCP to query for each provider's pricing, specs, and benchmarks.
2. Reads 10+ source pages using the Firecrawl/reader MCP.
3. Returns a structured markdown table with all the fields above, including citations.

**Expected output shape:**
```markdown
| Provider | Model | Input $/1M | Output $/1M | Context | Multimodal | Tool Use | HumanEval | Source |
|---|---|---|---|---|---|---|---|---|
| OpenAI | GPT-4o | 2.50 | 10.00 | 128K | Yes | Yes | 90.2% | https://openai.com/... |
| ... |
```

### Step 2: Build the Comparison Table in Excel

**Prompt:**
```text
Take the research table from the previous step and write it to an Excel file at `llm_comparison.xlsx` with these requirements:
- Each provider gets its own worksheet tab (OpenAI, Anthropic, Google, DeepSeek)
- Include a "Summary" tab that ranks all models by value score (quality per dollar, using HumanEval score divided by average cost)
- Make the input/output price columns numeric so they can be sorted and filtered
- Add a "Last Updated" cell in the top-right corner of each sheet with today's date
- Use Python with pandas and openpyxl. Create the script and run it.
```

**What the agent does:**
1. Writes a Python script using `pandas` and `openpyxl`.
2. Parses the markdown table from Step 1.
3. Creates the workbook with per-provider sheets and a Summary sheet.
4. Saves `llm_comparison.xlsx` in the working directory.

### Step 3: Generate the Executive Summary

**Prompt:**
```text
Based on the comparison data, write an executive summary (200–300 words) answering:
- Which model offers the best value for coding tasks?
- Which model has the largest context window?
- Which providers support multimodal input (image + text)?
- What is the cost difference between the cheapest and most expensive option per 1M tokens?

Format as markdown with bold key findings and bullet lists.
```

### Step 4: Assemble and Export the Full PDF Report

**Prompt:**
```text
Combine the executive summary, the comparison table, and a conclusion (with recommendations for when to use each model) into a single PDF report. The report should be 4–6 pages with:
- A title page (title: "LLM Provider Comparison for Software Engineering, 2026")
- A table of contents
- Properly formatted tables (fit to page width)
- Citations under each table

Use Python with `reportlab` or `markdown2` + `weasyprint`. Save as `llm_provider_report.pdf`.
```

**What the agent does:**
1. Writes a Python script that converts the markdown content to formatted PDF.
2. Handles table pagination and citation formatting.
3. Saves the final PDF.

## Skills Demonstrated

- **Multi-tool orchestration** — search → extract → analyze → export across 3+ MCP tools
- **Data extraction from web pages** — parsing pricing tables and benchmark tables from heterogeneous HTML sources
- **Report generation** — combining prose, tables, and formatting into a professional PDF
- **File format conversion** — markdown → Excel (with tabs, filters, numeric columns) and markdown → PDF

## Common Pitfalls

- ❌ **Agent returns placeholder citations** — If the agent can't verify a price, it will hallucinate one. Require exact URLs and a verification step: "Cite the URL where you found each number."
- ❌ **PDF tables overflow page width** — Wide comparison tables often break PDF layout. Always specify `fit-to-width` or split into multiple pages.
- ❌ **Excel loses numeric formatting** — If the agent writes strings that look like prices into Excel, you can't sort by cost. Force numeric conversion in the Python script.
- ❌ **Missing sources** — Older training data means the agent doesn't know 2025/2026 pricing. Insist on fresh web search, not prior knowledge.

## Quick Reference

| Step | Prompt Theme | Tool/MCP | Output Format |
|---|---|---|---|
| 1 | "Research provider X, extract pricing and benchmarks, cite sources" | Web search MCP + Firecrawl | Markdown table |
| 2 | "Write to Excel with per-provider sheets and a summary tab" | Python (pandas/openpyxl) | `llm_comparison.xlsx` |
| 3 | "Write an executive summary answering specific questions" | LLM synthesis | Markdown prose |
| 4 | "Combine into a 4–6 page PDF with title and TOC" | Python (reportlab/weasyprint) | `llm_provider_report.pdf` |

## Key Takeaways

- The agent can chain **search → extract → synthesize → export** without you writing a single line of extraction code.
- **Excel is the deliverable** many business users expect; learning to produce filterable, sortable spreadsheets is a high-leverage skill.
- Always verify pricing/benchmark numbers — LLMs confidently state outdated figures. Force the agent to cite live sources.
