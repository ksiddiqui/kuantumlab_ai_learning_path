# Section 0: Prerequisites

> **Get your computer ready and build the foundational knowledge every AI agent developer needs.**

Before you can build and run AI agents, you need a working development environment and a mental model for how large language models actually work. This section gets you from zero to ready.

## What You'll Set Up

By the end of this section, you will have:

- A **working terminal** where you can navigate files, run commands, and manage your system
- **Python** installed and verified (you'll write scripts and talk to AI APIs)
- **VS Code** configured as your code editor with the right extensions
- **Git** installed so you can save, share, and roll back your code
- **Node.js** installed so you can run JavaScript tools and web servers
- A clear understanding of **tokens, context windows, and model parameters** — so you know why your agent "forgets" and how to work with that
- Fluency in **Markdown** — the text format every agent reads and writes

## Before You Start

This section assumes **zero terminal experience**. You do not need a computer science degree. You only need:

- A computer running **Windows**, **macOS**, or **Linux**
- The willingness to type commands and read error messages

> 💡 **Tip:** Follow the topic pages in order. Each one builds on the last. If a step doesn't work on your operating system, skip to the next — the concepts transfer.
